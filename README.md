# Zhilong Xue — Academic Homepage

A two-page static academic website, built with vanilla HTML, CSS, and a small
navigation script. GitHub Pages serves these files directly; no build is needed.

- `index.html`: Home.
- `research.html`: Research & CV, including selected publications and CV links.
- `CV_zhilong.pdf`: the complete academic record; retain this filename when updating.
- `cv-source/CV_zhilong.tex`: the corresponding public CV source.
- `cv.html` and `talks.html`: compatibility redirects; no content to maintain.

Maintain the full record in the CV, only a short selection in `research.html`,
and the single **Last updated** line at the end of `research.html`.
See `UPDATE_GUIDE_zh.md` for upload and maintenance instructions.

The existing `CNAME` retains `www.zhilongxue.cn`. Vite is optional and is used
only for local preview; it is not needed by GitHub Pages.
